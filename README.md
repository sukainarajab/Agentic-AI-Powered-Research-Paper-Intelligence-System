#  Agentic AI-Powered Research Paper Intelligence System

An AI-powered Research Paper Intelligence System that leverages **Agentic AI**, **Semantic Search**, and **Large Language Models (LLMs)** to help users efficiently explore and analyze Machine Learning research papers.

The system retrieves relevant research papers using semantic similarity, generates concise summaries, extracts important keywords, and compares research papers using LangChain-powered tools.

---

##  Features

-  Semantic Search using SentenceTransformers and FAISS
-  Retrieve relevant research papers from 15,000+ ML ArXiv paper abstracts
-  Abstractive summarization using Facebook BART
-  Keyword extraction using KeyBERT
-  Agentic AI implementation using LangChain tools
-  Tool Binding and Tool Invocation with Groq Llama 3.1
-  Research paper comparison based on:
  - Research Objective
  - Methodology
  - Key Contributions
  - Advantages
  - Limitations
  - Applications

##  Project Workflow

1. User enters a research query.
2. SentenceTransformer converts the query into embeddings.
3. FAISS retrieves the most relevant research papers.
4. BART generates a concise summary.
5. KeyBERT extracts important keywords.
6. LangChain tools enable Agentic AI workflows.
7. Users can also compare two research papers using the comparison tool.
